## 복습 메뉴

| 일본어 (입문) | 영어 (중급) |
| --- | --- |
| 50음도 (연상 그림·발음) | 오늘의 복습 (한→영 말하기·쓰기·따라 하기) |
| 따라 쓰기 | 내 표현 (별표·직접 추가) |
| 글자 카드 | 내 실수 고치기 |
| 단어 카드 | 듣고 쓰기 |
| 내 약점 | 표현 찾아보기 |

카드는 「다시 / 헷갈려요 / 알아요」로 표시하면 알맞은 날에 다시 나와요.

## 구성

```
language/
├─ index.html          ← 복습 도구 (notes 폴더의 노트를 읽어서 카드를 만듦)
├─ img/kana/           ← 50음도 연상 그림
└─ notes/
   ├─ index.json       ← 복습 도구가 읽을 노트 목록
   ├─ 일본어/날짜.md
   └─ 영어/날짜-회차.md
```

## 노트에서 카드를 만드는 규칙

노트의 표 머리줄(첫 줄)을 보고 어떤 문제로 쓸지 정해요.

| 표 머리줄 | 쓰이는 곳 |
| --- | --- |
| `행 \| ㅏ \| ㅣ \| ㅜ \| ㅔ \| ㅗ` (칸 내용: `あ 아`) | 일본어 배운 글자 (글자 카드·따라 쓰기) |
| `히라가나 \| 발음 \| 뜻` | 일본어 단어 카드 |
| `글자 \| 맞는 읽기 \| 헷갈린 읽기 \| 구별법` | 일본어 내 약점 |
| `… 영어 표현 … \| 뜻` | 영어 오늘의 복습·듣고 쓰기 |
| `자주 한 실수 \| 맞는 표현 \| 규칙` | 영어 내 실수 고치기 (규칙에 "졸업"이 있으면 제외) |

## 새 노트 추가하기

1. `notes/일본어/` 또는 `notes/영어/`에 노트 파일을 올려요.
2. `notes/index.json`에 파일 이름과 회차 이름을 한 줄 추가해요.
3. 1~2분 뒤 새로고침하면 반영돼요.
