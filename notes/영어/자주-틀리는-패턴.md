# 영어 자주 틀리는 패턴

수업 때마다 반복해서 나온 실수와 맞는 규칙이에요. 여행 전에 이 표부터 훑어보세요. (마지막 반영: 6회차, 2026-11-25)

| 자주 한 실수 | 맞는 표현 | 규칙 |
| --- | --- | --- |
| Is it usually traffic jam here? / I feel like it's a traffic jam all day. | Is there usually a traffic jam here? / I feel like there's a traffic jam all day. | 있다 = there is, It은 이미 말한 것 (6회차 2번, 복습 1순위) |
| There is next to the bank. | It's next to the bank. | 이미 말한 장소는 It's |
| Always traffic bad in Seoul. | The traffic is always bad in Seoul. | 주인공과 동사 빠뜨리지 않기 |
| The street food is famous for in Penang. | Penang is famous for its street food. | 주인공은 유명한 곳 |
| Could you show me in the map? / Could you say that slowly? | Could you show me on the map? / Could you say that more slowly? | 작은 단어(on, more, to, at, it) 빠뜨리지 않기 |
| Do you have a available room? | Do you have an available room? | 모음 소리 앞에는 an |
| I ran the marathon last year. / I'm going to run in Penang International Marathon. | I ran a marathon last year. / I'm going to run in the Penang International Marathon. | 처음은 a, 대회 이름 앞에는 the |
| I'll try the local food after run. | I'll try the local food after running. | after/before 뒤 동사는 ~ing |
| It's a second marathon. | It's my second marathon. | 몇 번째는 my / the (6회차 정답) |
| I've run one last year. | I ran one last year. | 정해진 과거는 과거형 (6회차 정답) |
| I visited last year in Japan. | I visited Japan last year. | 장소 먼저, 시간 맨 뒤 |
| Only one day, please. (호텔) | Only one night, please. | 호텔은 밤 단위 |
| This shoes is a little big. | These shoes are a little big. | 신발·국수는 여러 개 모양 |
| It's fit on me. / It's a big. | It fits me. / It's a little big. | It 뒤 동사 -s, 조금 = a little |
| Can I try on this? | Can I try this on? | this/it은 try와 on 사이에 |
| This soup is salt. | This soup is too salty. | salt=소금, salty=짠, 너무 = too |
| I want to have a breakfast. | I want to have breakfast. | 아침·점심·저녁 앞에는 a 없음 |
| Could you make less spicy? | Could you make it less spicy? | 앞에서 말한 것은 it |
| I'm alone. (식당 인원) | Just one, please. | I'm alone은 "외로워"처럼 들려요 |
| Tell me again. | Could you say that again? | Tell me는 명령처럼 들려요. 부탁은 Could you ~? |

졸업한 패턴: 동작 연결과 장소·시간 위치(I'll A before the race and B after the race), 나열, want to 위치, try + 음식, 관사 a
