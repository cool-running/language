# 영어 5회차 (2026-11-24): 호텔 문제 해결과 잡담

예약이 꼬였을 때 해결하는 표현과, 호텔 직원과 잡담하는 표현이에요. 오늘부터 한 문장이 아니라 두 문장 이상으로 말하는 연습을 시작했어요.

## 예약 문제 해결

| 영어 표현 | 뜻 |
| --- | --- |
| I'm sure I made a reservation. I have a confirmation email. Here it is. | 분명히 예약했어요. 확인 메일 있어요. 여기요. |
| Do you have any rooms available tonight? | 오늘 밤 빈방 있어요? |
| Can I change my reservation to tonight? | 예약을 오늘 밤으로 바꿀 수 있어요? |
| Yes, it's okay because I only need it for one night. | 괜찮아요. 하룻밤만 필요하니까요. |
| How much is it per night? | 1박에 얼마예요? |

## 잡담과 경험 말하기

| 영어 표현 | 뜻 |
| --- | --- |
| I'm here to run the marathon. | 마라톤 뛰러 왔어요. |
| I'm going to try the local food and relax. | 현지 음식 먹어 보고 쉬려고요. |
| I think it's my third or fourth marathon. | 이번이 서너 번째 마라톤인 것 같아요. |
| I ran one last year. | 작년에 하나 뛰었어요. |
| This is my first time in Penang. I visited Japan last year. | 페낭은 처음이에요. 작년엔 일본에 갔어요. |

## 알아두면 좋은 것

- 이미 말한 장소가 어디 있다고 할 때는 **It's** next to the bank. **There is**는 뒤에 물건이 와요.
- 호텔은 밤 단위: one **night**, three **nights**, per **night**.
- "~로 바꾸다" = **change A to B**.
- "~인 것 같아요" = 문장 앞에 **I think**. 서너 번 = **three or four**.
- 몇 번째인지 말할 때는 **my / the**: my first time, my third marathon.
- 언제인지 정해진 과거(last year)는 과거형 **I ran**. 언제인지 없으면 **I've run** (해 본 적 있다).
- 지도에서 = **on** the map. 조금 더 천천히 = **more** slowly.
- 신발은 항상 여러 개: **These shoes are** a little big.
