# 영어 1회차 (2026-11-20): 호텔과 여행 기본 표현

| 상황 | 영어 표현 | 뜻 |
| --- | --- | --- |
| 호텔 체크인 | Hi, I have a reservation under Kyung Tae Kim. | 김경태 이름으로 예약했어요. |
| 식당 자리 | Could we sit by the window? | 창가에 앉아도 될까요? |
| 자리 개수 | a window seat (혼자) / window seats (여러 명) | 창가 자리 |
| 음식 | I want to try the local food. | 현지 음식을 먹어 보고 싶어요. |
| 달리기 | run on the beach / run along the beach | 해변(모래) 위에서 / 해변을 따라서 달리다 |
| 관심 | I'm interested in visiting many countries. | 여러 나라에 가 보는 데 관심이 있어요. |
| 여행 이유 | I want to experience their culture, try the food, find famous restaurants, and run everywhere. | 그 나라 문화를 체험하고, 음식을 먹어 보고, 맛집을 찾고, 어디서나 달리고 싶어요. |

철자 연습: **restaurant** (r-e-s-t-a-u-r-a-n-t)
